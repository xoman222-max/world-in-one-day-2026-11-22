A single 1024×1024 newspaper front page summing up the world news of Sunday 22 November 2026, with hand-drawn inline SVG illustrations, lead stories, eight story cards, key numbers and a region legend. `entry.png` is the rendered poster submitted to the make.fun bounty.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

## How it is made

`poster.html` is a self-contained 1024×1024 page drawn by hand in HTML and inline SVG. `render.sh` renders it to `entry.png` with headless Chrome, keeping the file under 1 MiB.
